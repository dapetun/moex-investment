# MOEX Portfolio Optimizer

Автоматизированный инструмент для подбора оптимального инвестиционного портфеля акций Московской биржи. Загружает данные, фильтрует акции, находит группу с минимальными корреляциями и рассчитывает оптимальные веса через несколько финансовых моделей.

---

## Что делает этот проект?

Вы запускаете одно нажатие кнопки — и система сама:

1. Загружает список **всех акций MOEX** через официальный API
2. Скачивает **2 года истории цен** для каждой акции
3. **Фильтрует** — убирает неликвидные, аномальные, «мёртвые» акции
4. Строит **граф корреляций** — находит акции, которые движутся независимо друг от друга
5. Находит **максимальную клику** — группу акций, где **каждая пара** слабо коррелирована
6. Рассчитывает **оптимальные веса** тремя разными методами
7. Показывает **все метрики риска** — VaR, CVaR, просадки, Monte Carlo
8. Позволяет **экспортировать** результат в Excel и PDF

## Как пользоваться дашбордом

### Боковая панель (слева)

Здесь вы настраиваете параметры:

| Параметр | Что означает | Значение по умолчанию |
|----------|-------------|----------------------|
| **Correlation threshold** | Порог корреляции: если |корреляция| между двумя акциями ниже этого числа, они считаются «независимыми». **Чем ниже** — тем строже отбор. | 0.25 |
| **Min daily turnover** | Минимальный средний дневной оборот акции в млн руб. Акции с маленьким оборотом неликвидны — их сложно купить/продать. | 50 млн |
| **Max weight per asset** | Максимальная доля одной акции в портфеле. Если 30% — ни одна акция не будет весить больше трети. | 30% |
| **Risk-free rate** | Безрисковая ставка (годовая). Используется для расчёта Sharpe ratio. Обычно равна ставке по ОФЗ. | 0% |
| **Covariance method** | Как считать ковариационную матрицу (см. раздел «Методы ковариации» ниже). | sample |
| **Monte Carlo simulations** | Сколько случайных сценариев смоделировать. Больше = точнее, но дольше. | 10 000 |
| **Rebalance frequency** | Как часто ребалансировать портфель (в торговых днях). 21 день ≈ 1 месяц. | 21 |
| **Transaction cost** | Транзакционные издержки в базисных пунктах. 10 bps = 0.1%. | 10 |
| **Black-Litterman tau** | Параметр неопределённости в модели Black-Litterman. Больше = больше доверия к views. | 0.05 |
| **BL: auto-views count** | Сколько автоматических views создавать для Black-Litterman. | 5 |
| **HRP clustering** | Метод кластеризации для HRP: single, complete или average linkage. | single |
| **Use cached data** | Использовать скачанные ранее данные (не обращаться к API заново). | Да |

### Нажимаете «Run Optimization»

Начинается полный пайплайн. Обычно занимает 30-60 секунд (если данные уже кэшированы — 2-3 секунды).

## Вкладка 1: Portfolio (Главная)

**Что показывает:** Оптимальный портфель с максимальным Sharpe ratio.

**Что здесь есть:**
- **График весов** — какую долю занимает каждая акция
- **4 основные метрики:** годовая доходность, волатильность, Sharpe ratio, безрисковая ставка
- **4 метрики риска:** VaR 95%, CVaR 95%, Sortino ratio, метод ковариации
- **Кривая роста капитала** — как рос бы портфель за 2 года (историческая симуляция)
- **Min Variance портфель** — альтернатива с минимальным риском

### Что означают метрики?

| Метрика | Простым языком |
|---------|---------------|
| **Annual Return** | Сколько портфель в среднем зарабатывает за год (в %) |
| **Annual Volatility** | Насколько сильно «прыгают» доходности портфеля. Чем выше — тем нестабильнее |
| **Sharpe Ratio** | Доходность на единицу риска. **Чем выше — тем лучше.** >1 хорошо, >2 отлично |
| **Sortino Ratio** | Как Sharpe, но считает только «плохую» волатильность (падения). >2 хорошо |
| **VaR (95%)** | Value at Risk. С вероятностью 95% за один день вы не потеряете больше этой доли |
| **CVaR (95%)** | Conditional VaR. Средние потери, если VaR всё-таки превышен. «Худший средний день» |
| **Max Drawdown** | Максимальное падение от пика до дна. Чем ближе к 0 — тем лучше |

## Вкладка 2: Efficient Frontier (Эффективный фронтier)

**Что это:** График, показывающий все «оптимальные» портфели — от минимально рискового до максимально доходного.

**Как читать:**
- **По оси X** — риск (волатильность, %)
- **По оси Y** — доходность (%)
- **Красная звезда** — портфель с максимальным Sharpe (лучшее соотношение риск/доходность)
- **Синяя звезда** — портфель с минимальным риском
- **Цвет точек** — Sharpe ratio (тёплый = лучше)

**Зачем нужно:** Чтобы увидеть компромисс между риском и доходностью и выбрать портфель по自己的 вкусу.

---

## Вкладка 3: Monte Carlo (Моделирование)

**Что это:** 10 000 случайных сценариев развития портфеля на год вперёд.

**Как работает:**
1. Берём средние доходности и ковариацию акций
2. Генерируем 10 000 случайных «миров» (многомерное нормальное распределение)
3. В каждом «мире» считаем доходность, риск и просадку портфеля

**Что показывает:**
- **Гистограммы** — распределение доходности, волатильности и просадки
- **Таблица процентилей** — «В 90% случаев доходность будет выше X%»

**Зачем нужно:** Понять, насколько надёжны прогнозы. Если распределение очень широкое — прогноз нестабилен.

## Вкладка 4: Graph Analysis (Графовый анализ)

**Что это:** Уникальная фича проекта — визуализация графа корреляций.

**4 графика:**
1. **Полный граф** — все акции как точки, линии соединяют слабо коррелированные пары
2. **Клика на фоне графа** — найденная группа выделена оранжевым
3. **Только клика** — изолированное view найденной группы
4. **Тепловая карта клики** — попарные корреляции внутри группы (все < 0.25)

**Что такое клика:** Группа акций, где **каждая пара** имеет |корреляцию| < порога. Это значит, что акции движутся максимально независимо —理想的ная диверсификация.

## Вкладка 6: Rebalancing (Ребалансирование)

**Что это:** Сравнение двух стратегий:
1. **Rebalancing** — раз в N дней возвращаем веса к целевым (продаём подешёвшие, покупаем подорожавшие)
2. **Buy & Hold** — купил и забыл

**Метрики:**
- Доходность обеих стратегий
- Sharpe ratio
- Общая стоимость транзакций (сколько денег «съели» комиссии)
- Количество ребалансировок
- Максимальная просадка

**Зачем нужно:** Понять, стоит ли тратить деньги на комиссии за ребалансирование или лучше просто держать.

## Вкладка 7: Stress Test (Стресс-тестирование)

**Что это:** Как бы выглядел ваш портфель во время реальных кризисов.

**5 предопределённых сценариев:**

| Сценарий | Период | Что произошло |
|----------|--------|---------------|
| COVID Crash | Фев-Май 2020 | Пандемия, обвал рынков |
| 2022 Geopolitical | Фев-Июн 2022 | Санкции, война |
| 2018 Russian Crisis | Янв-Апр 2018 | Торговые войны |
| 2014 Oil Crash | Июн 2014-Янв 2015 | Падение нефти, девальвация рубля |

**Для каждого сценария:**
- Доходность портфеля за период кризиса
- Максимальная просадка
- Самый плохой день и дата
- Количество дней до восстановления

## Вкладка 8: Black-Litterman

**Что это:** Продвинутая модель оптимизации, которая сочетает:
- **Рыночное равновесие** — что «думает рынок» в целом
- **Ваши views** — ваши мнения о том, какие акции лучше

**Как работает:**
1. Из рыночных весов вычисляются «имплицированные доходности» — доходности, которые рынок уже заложил
2. Вы добавляете свои views («акция A лучше акции B»)
3. Модель математически «объединяет» рыночное равновесие с вашим мнением
4. Получаются posterior доходности и ковариация → оптимизация

**Что показывает:**
- Веса по Black-Litterman
- Матрица views (P) и целевые доходности (Q)
- Сравнение: Markowitz vs Black-Litterman

**Зачем нужно:** Black-Litterman даёт более стабильные веса, чем классический Markowitz. Не «улетает» в крайности.

---

## Вкладка 9: HRP (Hierarchical Risk Parity)

**Что это:** Современный подход к распределению весов (Lopez de Prado, 2016).

**Как работает:**
1. Акции группируются в кластеры по корреляционному расстоянию
2. Портфель рекурсивно делится пополам
3. Веса распределяются **обратно пропорционально дисперсии** каждого кластера

**Преимущества:**
- **Не требует обращения ковариационной матрицы** (более стабильно)
- Учитывает иерархическую структуру рынка
- Менее чувствителен к шуму в данных

**Что показывает:**
- Веса HRP
- Таблица сравнения: Markowitz vs BL vs HRP vs Min Variance

## Вкладка 10: Rolling Correlation (Скользящие корреляции)

**Что это:** Как корреляции между акциями **меняются со временем**.

**2 графика:**
1. **Rolling Correlation** — линии показывают, как корреляция между парами акций меняется в скользящем окне
2. **Rolling Beta** — как бета каждого актива меняется со временем

**Зачем нужно:** Корреляции не стабильны. Если в кризисы корреляции растут (все акции падают вместе), диверсификация может не сработать в самый нужный момент.

## Использование как библиотеки

```python
from moex_portfolio.data_loader import load_all_data, get_all_shares
from moex_portfolio.filters import prepare_returns
from moex_portfolio.graph_analysis import build_correlation_graph, find_max_clique
from moex_portfolio.risk_models import covariance_matrix
from moex_portfolio.optimizer import max_sharpe_portfolio, efficient_frontier
from moex_portfolio.analytics import monte_carlo_simulation, var_historical
from moex_portfolio.metrics import portfolio_metrics

# 1. Загрузка данных
tickers = get_all_shares()
data = load_all_data(tickers)

# 2. Фильтрация
returns, valid_tickers = prepare_returns(data)

# 3. Графовый анализ
corr = returns.corr()
G = build_correlation_graph(corr, threshold=0.25)
clique = find_max_clique(G)

# 4. Оптимизация
clique_returns = returns[clique]
mean_ret = clique_returns.mean()
cov = covariance_matrix(clique_returns, method="ledoit_wolf")

result = max_sharpe_portfolio(mean_ret, cov, max_weight=0.3)
print(f"Доходность: {result['return']:.2%}")
print(f"Волатильность: {result['volatility']:.2%}")
print(f"Sharpe: {result['sharpe']:.3f}")

# 5. Метрики
metrics = portfolio_metrics(result['weights'], mean_ret, cov, returns=clique_returns)
print(metrics)

# 6. Monte Carlo
mc = monte_carlo_simulation(mean_ret, cov, result['weights'], n_simulations=10000)
print(f"Средняя доходность MC: {mc['annual_return'].mean():.2%}")

# 7. VaR
var = var_historical(clique_returns, result['weights'], confidence=0.95)
print(f"VaR 95%: {var:.2%}")
```
