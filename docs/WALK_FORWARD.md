# Walk-forward сравнение стратегий

Исследовательский интерфейс: `moex_portfolio.walk_forward.walk_forward_compare`.
Он не входит в `optimize` и не запускается skill или ботами. Старый
`walk_forward_backtest` не изменён.

Производительность в отчёте — out-of-sample. Математическое ожидание и
ковариация считаются только по ценам до даты решения. Первая тестовая дата
строго позже последней даты окна. Пропуски цен удаляются, а не заполняются.

Equal Weight возвращается к 1/N только в даты пересмотра. Buy-and-hold
после первого формирования больше не торгует. Если 1/N или лимит
невыполнимы, шаг получает отказ. Лимит не поднимается до 1/n.

Первое формирование идёт из кэша. Односторонний оборот тогда равен сумме
покупок, а не автоматически `0.5 * Σ|Δw|` по пустой книге. Дальше оборот
берётся из `assess_turnover`, только когда обе книги суммируются в 1.
Издержки вычитаются из капитала один раз: `one_way * value * bps / 10000`.

Пример:

```text
python scripts/run_walk_forward_example.py
```

Сводка пишется в `docs/examples/walk_forward_synthetic.json`. Цены
синтетические. Это не оценка российского рынка.
